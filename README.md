# 🍎 石榴人 3D · 梁梦冉

一个**纯静态、零依赖、可离线运行**的 3D 互动页面：打开就是一颗长着大眼睛的石榴人，
可以用手（或鼠标）任意拖动环绕观看、放大缩小，背景是流动的抽象光场。

**这一版是为梁梦冉做的**：头顶悬浮一块跟着转的名字铭牌（刻着「梁梦冉 / LIANG MENG RAN」），
左上角也写着送给谁，角色的眼睛还会一直跟着镜头看。

> **直接部署**：把整个文件夹原样丢到任意静态托管（Cloudflare Workers / GitHub Pages /
> Vercel / Nginx / 对象存储 / 甚至 U 盘）即可，不需要构建、不需要后端、不需要联网。

## 目录结构

```

```

## Cloudflare 部署（Workers）

仓库已经配好，**在 Cloudflare 控制台连接本仓库后不需要任何构建命令**，
部署命令保持默认的 `npx wrangler deploy` 即可直接发布：

- `wrangler.jsonc` 里的 `assets.directory = "./public"` 告诉 wrangler 把 `public/` 当静态站点托管；
- 纯静态资源托管，**不产生请求计费**，也不消耗 Worker 脚本 CPU 时间；
- `name` 需与面板上该 Worker 的项目名一致（CI 会自动用面板名覆盖，不一致只会打一条 warning）。

改内容：直接编辑 `public/index.html`，提交即自动重新部署。

## 石榴人的造型是怎么来的

全部几何用 three.js 参数化生成，**零外部素材**：

- **果身**：绕 Y 轴的旋转对称曲面。轮廓用超椭圆 `(1-x²)^0.4`，底部用「平滑取大」
  收成一个能站稳的圆底（直接硬取大在交界处会留一圈折角，看起来像果身坐在盆里）；
  顶部向上平滑收细，**果冠不是另扣上去的零件**，而是同一张果皮曲面延续出来的。
- **果冠**：一张自定义的「扇贝状外张曲面」——从果颈向上、向外张开，
  顶端边缘按角度起伏成 6 个尖齿。真石榴的冠是空心的杯，所以另有一层内壁，
  否则从侧上方看进去会看到外壁背面（法线朝外，渲出来发黑）。
- **果皮颜色**：用顶点色在同一张网格上把「果身红 → 果冠深红」渐变过去，接缝天然不存在。
- **四肢 / 脸**：细长四肢 + 白手套白鞋；挂点角度取在果身**侧面**
  （果身是很宽的球，挂点靠正面会让整条手臂埋进肚子轮廓里看不见）。

## 自检

无浏览器环境下也能验证（容器/服务器里没有 GPU 时照样跑）：

```bash
node tools/verify.mjs            # 静态：资源引用 / import 符号 / DOM id / 离线合规（31 项）
node tools/integration-test.mjs  # 运行期：真实实例化场景与角色，连跑多帧（68 项）
node tools/glsl-check.mjs        # 着色器：用真正的 GLSL 解析器校验 5 段着色器 + 语义检查
node tools/api-check.mjs         # three.js r169 用到的 API 是否存在
node tools/single-file-test.mjs  # 单文件版：真实执行内联脚本并检查导出（65 项）
node tools/plate-check.mjs       # 铭牌：贴图文字 / 材质 / 悬挂位置（27 项）
node tools/preview.mjs           # 用自写软件光栅化器出图到 shots/，目视检查造型
```

`tools/preview.mjs` 是一个纯 JS 的 Z-buffer 光栅化器：直接读 three.js 的几何体、
自己做顶点投影与 Lambert 着色，再用 `node:zlib` 手写最小 PNG 编码落盘，
所以在没有浏览器和 GPU 的环境里也能"看到"造型。
